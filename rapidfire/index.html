Rapidfire

A keyboard launcher made for you.

Version 1.0, released 21 November 2026. Free to download; a license is $20, one-time, for 3 Macs.

Free to download, or installed with Homebrew. A license adds more palettes.

Press a hotkey. Rapidfire shows the links, apps, files and Shortcuts kept in it and marks, in each name, the letters that tell it apart. Type them, and it opens. There is no Return to press and no name to recall.

Rapidfire is AI-first and MCP-ready, so you can make it exactly as you want it. Connect an AI assistant and ask it, in plain words, to build palettes, shorten names or move triggers. Every change it makes is listed and can be reverted.

Read the documentation

Keys without setup

  • Two or three keys reach a trigger among hundreds.
  • The same names give the same keys, on every Mac.
  • A trigger opens the moment it is the only one left.

Anything with a link

  • Web pages, apps, files and folders, Shortcuts, BetterTouchTool and Keyboard Maestro actions, System Settings panes.
  • A link can ask for text first: one trigger searches a website or hands text to a Shortcut.
  • Holding Control opens a whole palette at once.
  • Dragging a URL from a browser, or a file, a folder or an app, onto the menu bar icon opens Quick Add.

Habits are protected

  • Before a trigger is added, Rapidfire lists the triggers whose keys it would change, most used first.
  • Locked keys reserve exact keys for one trigger.
  • Every change can be undone.

A library that stays manageable

  • Palettes group triggers, each with its own hotkeys, and any palette can be shown inside another.
  • Show All unfolds every folder, so the whole library is on screen at once.
  • A dynamic palette shows a different palette by time, network or the app in front.

One hand is enough

With one hand on the mouse, every key of the far half of the keyboard is typed with its mirror key on the near half.

Works with the rest of the Mac

  • iCloud sync keeps the library the same on every Mac.
  • Spotlight, Siri and the Shortcuts app can find and open triggers.
  • An AI assistant can read and edit the library through Rapidfire's MCP server; every change it makes is listed and can be reverted.
  • VoiceOver, Voice Control, Switch Control and keyboard-only use are supported.

Download

Rapidfire 1.0 is a disk image of 7.6 MB. Open it and drag Rapidfire to the Applications folder. Rapidfire updates itself from then on.

With Homebrew, the two lines at the top of this page do the same. Homebrew 7 and later install a cask from outside Homebrew's own collection only after it has been trusted; that is the first line. Older versions need only the second.

The download is free and works without a license: one palette, General, complete and with no time limit.
