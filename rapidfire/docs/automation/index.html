Rapidfire Help

Automation

Rapidfire works with other tools on the Mac. Other apps can show a palette, add triggers, and read what is kept in Rapidfire, through links, through the Shortcuts app, and by dragging and copying.

Overview

Rapidfire keeps links and opens one after a few keys. It does not run scripts or move windows itself: a trigger opens a link, and the app that owns the link does the work. Automation connects the two sides.

  • Show a palette from another app: a gesture, a key on a Stream Deck, a macro, a voice command.
  • Add triggers from another app: the page open in a browser, a file in Finder, a list of links.
  • Put Shortcuts, BetterTouchTool triggers and Keyboard Maestro macros on a palette, each with a name and visible keys.
  • Use triggers in the Shortcuts app: find them, run them, or run a whole palette on a schedule.

Open a Palette from Another App

Every palette has a link. Any app that can open a link can use it to show that palette, just as the palette's hotkey would.

  1. Open the editor and Control-click the palette in the sidebar.
  2. Choose Copy Link to Open Palette, then With Both Hands, With the Left Hand or With the Right Hand.
  3. Paste the link into the other app: for example, an Open URL action in BetterTouchTool or Keyboard Maestro, or a Website key on a Stream Deck.

rapidfire://open?palette=Dev&hand=left

The same link is in Palette Settings, under From Other Tools. The palette can also be dragged out of the sidebar and dropped into the other app.

The link uses the palette's name. After renaming the palette, copy the link again.

Open everything in a palette at once

To open every trigger in a palette with one link, as holding Control in the overlay does, Control-click the palette and choose Copy Link to Run Palette. This link contains a key made on this Mac, like a link that runs a single trigger. The General palette cannot be run this way.

A palette large enough for Settings > Keys > Confirm before opening many is asked about first: the overlay opens with the question, and Return opens the palette.

rapidfire://run?palette=Morning

Open a whole palette with a trigger

A trigger can open a whole palette too. Give the trigger the link below as its URL, with the palette's name after palette=. Picking the trigger opens every trigger in that palette, as holding Control does. The link needs no key here, because it is opened inside Rapidfire and never leaves it.

rapidfire://run?palette=Morning

The trigger can be in the palette it opens. It then opens everything else in that palette: with the palette on the keys ee and the trigger on e, typing eee opens the whole palette.

A whole palette opened at once leaves out the triggers whose link starts with rapidfire://, so opening one palette never starts another. When some were left out, Rapidfire says how many. To open several palettes together, show them inside one palette.

When a trigger or a link opens a whole palette, triggers marked New or Changed and triggers that run a program or an installer are left out, and Rapidfire says how many.

When another app asks for the same palette more than three times within ten seconds, Rapidfire stops opening it and says so. Opening the palette in Rapidfire lifts that.

After renaming the palette, change the name in the trigger's URL. The palette's ID in place of its name keeps working.

Open a Trigger from Another App

A trigger has a link too. Use it when another app should open one particular trigger: a key on a Stream Deck, a keyboard shortcut in BetterTouchTool, a macro.

  1. In the editor, Control-click the trigger.
  2. Choose Copy Link to Trigger, then That Runs It.
  3. Paste the link into the other app.

The link contains a key of its own, which only this Mac can make. With it, the trigger opens at once. A link without the key, such as one written by hand or copied with That Shows It, shows the trigger in its palette instead, where Return opens it.

rapidfire://trigger?name=Docs&palette=Dev

Keep links that contain a key private. A key opens only the trigger or palette its link was copied for. If one gets out, choose New Key in Settings > General: links copied before then stop opening triggers.

Add Triggers

Drag and drop

  • Drag a link, a file, a folder or an app onto Rapidfire's icon in the menu bar. Quick Add opens with its name and address; choose a palette and press Return.
  • Drag several items at once, or a piece of text that contains links, such as a list in a note or a selection on a web page. They open in the Import window as a new palette, which can be renamed there, with items to untick and the keys that would change, before anything is added.
  • In the editor, drop or paste items into the table to add them to the palette that's showing.

From a link

A link that starts with rapidfire://add opens Quick Add filled in. Nothing is added until Add is pressed.

rapidfire://add?url=https%3A%2F%2Fexample.com%2Fdocs&name=Docs&palette=Dev

The page open in a browser

Make a bookmark with the address below. Choosing the bookmark opens Quick Add with the page's title and address. The browser may ask once per website whether it may open Rapidfire.

javascript:location.href='rapidfire://add?url='+encodeURIComponent(location.href)+'&name='+encodeURIComponent(document.title)

From the Shortcuts app

The Add Trigger action adds a link or a file from a Shortcut. A Shortcut that uses it can add from the Share menu, the Services menu, or a quick action in Finder. For a file, a folder or an app, connect it to the action's File field: that gives Rapidfire access to it.

Add Shortcuts as Triggers

A Shortcut can be a trigger. Rapidfire lists the Shortcuts on this Mac, so the link need not be written by hand.

  1. Open the editor and select the palette the trigger should go in.
  2. Choose File > New Trigger from Shortcut, then the Shortcut. Shortcuts in folders are in submenus.

The trigger is named after the Shortcut and runs it when picked. To give the Shortcut input, add one of these to the end of the trigger's address:

&input=clipboardThe Shortcut receives what was last copied.
&input=text&text=HelloThe Shortcut receives the text after text=.

Rapidfire reads the names of the Shortcuts on this Mac to show the menu. It doesn't run them, and nothing leaves the Mac.

Ask for Input When a Trigger Opens

A trigger's link can contain input fields. When the trigger is picked, Rapidfire asks for each field, puts what is typed into the link, and opens it. Use input fields to search a website, or to pass text to a Shortcut or a macro.

https://www.youtube.com/results?search_query={Search}

Add an input field

  1. In the editor, click the trigger's URL.
  2. Where the typed text should go, write a name in braces, for example {Search}. The name is the field's label.
  3. Press Return. An icon before the URL shows that the trigger asks for input. In the overlay, the trigger's name is followed by an ellipsis (…).

To find the link for a website's search, search for a word on the website, copy the address of the results page, and replace the word with the input field.

Fill in the fields

  1. Pick the trigger in the overlay. The input fields take the place of the list.
  2. Type the text. Press Tab to move to the next field.
  3. Press Return to open the trigger. Press Escape to cancel, or press Delete in the empty first field to go back to the list.

Default values and optional fields

  • {Search}: the field must be filled in.
  • {Language|pl}: the field starts with the text after the bar, which can be changed or left.
  • {Tag|}: the field may stay empty.
  • A name used twice is one field. What is typed goes to both places.

https://translate.google.com/?sl={From|en}&tl={To|pl}&text={Text}

Pass text to a Shortcut or a macro

Put the input field where the Shortcut, the Keyboard Maestro macro or the BetterTouchTool trigger takes its text.

shortcuts://run-shortcut?name=Make%20PDF&input=text&text={Text}

kmtrigger://macro=Paste%20Text&value={Text}

btt://trigger_named/?trigger_name=Upload&file={File Name}

Rapidfire encodes what is typed, so spaces and characters such as & and ? are passed on as text and cannot change where the link goes. Rapidfire does not keep what is typed.

A link can have up to 8 input fields. Input fields work in links, not in the paths of files and folders. To use a brace as part of a link, write %7B for { and %7D for }.

A trigger that asks for input is left out when a whole palette is opened at once.

Rapidfire in the Shortcuts App

Rapidfire adds these actions to the Shortcuts app. They also appear when their names are typed in Spotlight.

ActionWhat it does
Open PaletteShows a palette's overlay, with both hands or mirrored onto the left or right hand.
Run TriggerOpens one trigger, and hands it on to the next action.
Run PaletteOpens every trigger in a palette, as holding Control in the overlay does. A large palette asks first.
Run Trigger or PaletteRuns the trigger or palette with the given name.
Add TriggerOpens Quick Add filled in, to be confirmed. With Show Quick Add off, adds the trigger at once, marks it New, and hands it on to the next action.
Switch Dynamic PaletteChanges which palette a dynamic palette shows on this Mac. Nothing is opened, and Rapidfire stays in the background.
Find TriggersFinds triggers by name, palette, kind, or whether they're marked New or Changed, with sorting and a limit.
Find PalettesFinds palettes by name or by how many triggers they hold, with sorting and a limit.
Find in RapidfireType or say “find Rapidfire” and a name, in Spotlight or to Siri. Rapidfire shows where it is, or runs it, as set in Settings > General.

Find Triggers returns triggers with their details: name, palette, link, kind, alias, and whether they're marked New or Changed. Pass a detail to a later action, for example the link to Open URLs.

Triggers marked New or Changed, and triggers that run a program or an installer, aren't run by an action until they have been opened once from Rapidfire.

Dynamic Palettes

A dynamic palette holds no triggers of its own. It shows another palette, and switching it chooses which one. Use it when the same place in the launcher should show different things at different times: work websites during the day and personal ones in the evening, or the tools of the current project.

Make a dynamic palette

  1. Open the editor and click New Dynamic Palette at the bottom of the sidebar, or choose File > New Dynamic Palette.
  2. Type its name and press Return.
  3. In Palette Settings, under Show Inside, choose where it appears, for example in General, and whether it appears as all its triggers or as one entry.
  4. Under On This Mac, choose the palette it shows.

In the overlay, the dynamic palette then shows the triggers of that palette, and of the palettes shown inside it. While it shows nothing, it adds nothing to the overlay.

Choose its prefix

In Palette Settings, under Prefix, a dynamic palette uses either its own prefix or the prefix of the palette it shows. With its own prefix, the first keys stay the same whatever it shows. With the shown palette's prefix, the prefix changes with a switch. With no prefix, the shown triggers are listed among the others, and the keys of other triggers can change with a switch.

Switch a dynamic palette

  • In the editor: in Palette Settings, under On This Mac, or by Control-clicking the dynamic palette in the sidebar and choosing a palette from Shows.
  • From the menu bar: Control-click Rapidfire's icon, choose Dynamic Palettes, then the dynamic palette, then the palette to show.
  • From the Shortcuts app: use the Switch Dynamic Palette action. In an automation it can switch at a time of day, on joining a Wi-Fi network, when an app opens, or when a Focus turns on.
  • From another app: use a link. Control-click the dynamic palette in the sidebar, choose Copy Link to Switch Palette, then the palette to show.

rapidfire://switch?palette=Socials&to=Work

The copied link contains a key made on this Mac for that dynamic palette. To switch to a different palette, change the name after to= and keep the key. A link without the key switches nothing.

A switch never opens anything. If the overlay is open when a switch happens, it shows the change the next time it opens.

What a dynamic palette shows is kept on each Mac and isn't synced. The dynamic palette itself, with its name, prefix, hotkeys and where it's shown, syncs like any other palette. On another Mac it shows nothing until it is switched there.

For a switch that happens often, such as every time an app comes to the front, use the Switch Dynamic Palette action, or have the other app open the link in the background. Rapidfire then stays in the background.

What a dynamic palette can show

A dynamic palette can show any palette except General, another dynamic palette, or a palette that shows the dynamic palette inside itself. Triggers can't be added to a dynamic palette: add them to the palette it shows.

Examples

Open a palette on joining a Wi-Fi network

  1. In the Shortcuts app, choose Automation and add a new automation.
  2. Choose Wi-Fi and the network, for example the one at the office.
  3. Add the Open Palette action and choose the palette. To open everything in it at once, use Run Palette.

The same works for a time of day, connecting a display, or opening an app.

Keep a note, a task or a document on a palette

Many apps have a link for each item: Notes, Reminders, Obsidian, Things, Bear, Craft and others. Copy the item's link in that app, then drag it onto Rapidfire's icon or paste it into the editor. Picking the trigger opens that exact item.

obsidian://open?vault=Notes&file=Projects%2FPlan

Run a Shortcut on what was just copied

Add the Shortcut with File > New Trigger from Shortcut, then add &input=clipboard to the end of the trigger's address.

Open the morning’s websites together

Put them in a palette. Hold Control while picking any trigger in it to open the whole palette, or use the Run Palette action in an automation that runs at a time of day.

One key for a System Settings pane

System Settings panes have links too. Add one as a trigger:

x-apple.systempreferences:com.apple.BluetoothSettings

Keep pieces of text ready to paste

Rapidfire opens links and does not store text to paste. A Shortcut does that, and a trigger hands it the text.

  1. In the Shortcuts app, make a Shortcut named Copy Text with one action: Copy to Clipboard, set to copy the Shortcut Input.
  2. In Rapidfire, add a trigger for each piece of text, with a link like the one below. The text comes after text=, with spaces written as %20.
  3. Pick the trigger, then paste with Command-V.

shortcuts://run-shortcut?name=Copy%20Text&input=text&text=Kind%20regards

With an input field in place of the text, the same trigger asks for it first.

One key on a Stream Deck, one gesture, one spoken word

Anything that can open a link can open a palette: a Website action on a Stream Deck key, a trackpad gesture in BetterTouchTool, a macro in Keyboard Maestro, a voice command. Copy the palette’s link from Palette Settings, under From Other Tools, and give it to the other tool.

Take Triggers Out

  • Copy a trigger in the editor with Command-C. It pastes as a link with its name into notes and messages, and as its address into a browser.
  • To share whole palettes with someone who has Rapidfire, Control-click a palette and choose Copy Sharing Link or Export Palette.

Drag a link out

Dragging a trigger or a palette out of Rapidfire gives its link without opening a menu. Drop it into a note, a message, or another app's link field.

  • Drag a trigger out of the editor's table, or out of the overlay. The link shows the trigger in its palette.
  • Drag a palette out of the editor's sidebar, or drag a palette's row out of the overlay. The link opens the palette.
  • Hold Option at the start of the drag to get the link that runs it instead: the trigger opens at once, or every trigger in the palette opens. The General palette cannot be run this way, so its link always opens it.

A link dragged with Option contains a key that opens that trigger or palette. Keep it private.

Dragging inside the editor works as before: a trigger dropped on a palette in the sidebar moves there, and a palette dragged within the sidebar changes its place in the list.

Link Reference

Every Rapidfire link starts with rapidfire:// followed by one of these words. Parts are added after a question mark and separated by &. Spaces and special characters in a part must be percent-encoded; links copied from Rapidfire already are.

rapidfire://open

Shows a palette's overlay, as its hotkey would. With nothing after it: General.

PartMeaning
paletteThe palette's name, or its ID.
handleft, right or both. Left out: both.
allyes opens the folders in place (Show All), no closes them again. With it, a palette that is already showing stays open.
watchyes keeps the overlay open and draws it again whenever the library changes, no stops that. With it, a palette that is already showing stays open.

rapidfire://open?palette=Dev&hand=left

rapidfire://run

Opens every trigger in a palette at once, as holding Control in the overlay does. Only with the key this Mac made for it; without it, the palette is shown. As the URL of a trigger in Rapidfire it needs no key. General is never run this way.

PartMeaning
paletteThe palette's name, or its ID.
keyThe key this Mac made for this palette's link. Rapidfire adds it when the link is copied with Copy Link to Run Palette.

rapidfire://run?palette=Morning

rapidfire://trigger

Shows a trigger in its palette, highlighted, so Return opens it. With the key this Mac made for it, opens the trigger at once.

PartMeaning
nameThe trigger's name, or its ID.
paletteThe trigger's palette, when two triggers share the name.
keyThe key this Mac made for this trigger's link. Rapidfire adds it when the link is copied with Copy Link to Trigger, then That Runs It.

rapidfire://trigger?name=Docs&palette=Dev

rapidfire://switch

Switches a dynamic palette to show another palette, on this Mac. Only with the key this Mac made for that dynamic palette; without it, nothing is switched and the dynamic palette is shown. A switch never opens anything.

PartMeaning
paletteThe dynamic palette's name, or its ID.
toThe palette to show: its name, or its ID. Left out: nothing.
keyThe key this Mac made for this dynamic palette's links. Rapidfire adds it when the link is copied with Copy Link to Switch Palette; the same key works with any palette after to=.

rapidfire://switch?palette=Socials&to=Work

rapidfire://add

Opens Quick Add filled in. Nothing is added until Add is pressed. With nothing after it: an empty Quick Add.

PartMeaning
urlThe link, or a file's path, the new trigger opens.
nameThe trigger's name. Left out: the website's name.
paletteThe palette to suggest. A name that doesn't exist yet makes a new palette.
aliasA forced alias.

rapidfire://add?url=https%3A%2F%2Fexample.com%2Fdocs&name=Docs&palette=Dev

rapidfire://import

Opens the Import window with the palettes the link carries. Made by Copy Sharing Link.

rapidfire://editor

Opens the editor, on a palette if one is named.

PartMeaning
paletteThe palette's name, or its ID.

rapidfire://editor?palette=Dev

rapidfire://settings

Opens Settings, on a pane if one is named.

PartMeaning
panegeneral, hotkeys, overlay, keys, files, sync, mcp or license.

rapidfire://settings?pane=files

rapidfire://help

Opens Rapidfire Help.

PartMeaning
pageThe page to open, by the name in its address on the website: for example shortcuts or automation. Left out: the first page.

rapidfire://help?page=shortcuts

Privacy and Safety

  • A link can show a palette, a trigger or a window, or open Quick Add or the Import window for confirmation. A link cannot add a trigger without asking, or change or delete anything, because any web page can ask a browser to open a link.
  • A link opens a trigger, or a whole palette, by itself only when it contains the key this Mac made for it, which Rapidfire adds when the link is copied with That Runs It or Copy Link to Run Palette. A web page cannot know the key.
  • Even with the key, a link does not open a trigger marked New or Changed, or one that runs a program or an installer. It shows the trigger instead.
  • A link switches a dynamic palette only when it contains the key this Mac made for that dynamic palette. A switch changes which palette of the library is shown. It never opens, adds or deletes anything.
  • Actions in the Shortcuts app can find, run and add triggers, and switch a dynamic palette. They cannot edit or delete anything.
  • A trigger added without Quick Add is marked New until it has been opened once from Rapidfire.
  • A trigger's input fields are filled in only by the person at the Mac. A link, an action in the Shortcuts app or an AI assistant can open such a trigger, and Rapidfire then shows the fields to be filled in.
  • Everything described on this page happens on this Mac. Rapidfire sends nothing over the network for it.
