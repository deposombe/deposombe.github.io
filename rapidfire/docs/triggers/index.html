Triggers

A trigger is a name and a link. This page lists what a trigger can open, the ways of adding one, and what the marks next to a trigger mean.

Last updated 23 November 2026

What a Trigger Can Open

Rapidfire opens a trigger’s link the way double-clicking it in Finder would: the app that owns the link does the rest. Anything with a link can be a trigger.

https://example.comA web page, in the default browser.
/Applications/Notes.appAn app: it opens, or comes to the front when it is already open.
~/Documents/Plan.pdfA file or a folder. See Files and iCloud Sync for giving Rapidfire access to it.
shortcuts://run-shortcut?name=…A Shortcut from the Shortcuts app.
btt://trigger_named/?trigger_name=…A named trigger in BetterTouchTool.
kmtrigger://macro=…A macro in Keyboard Maestro.
x-apple.systempreferences:…A pane of System Settings.
obsidian://, raycast://, things:// …A note, a command or an item in any app that has links.
rapidfire://…One of Rapidfire’s own windows or palettes.

Rapidfire does not run scripts, paste text or move windows itself. A trigger that does such a thing points to a Shortcut or a macro that does it.

Add Triggers

By dragging

  • Drag a link, a file, a folder or an app onto Rapidfire’s icon in the menu bar, or onto the drop zone that appears under it. Quick Add opens.
  • Drag several things at once, or a piece of text that contains links. The Import window opens with them as a new palette to name and check.
  • Drag or paste into the editor’s table to add to the palette that is showing.

In Quick Add

  1. Check the name. A short name with distinctive first letters is quicker to type.
  2. Choose the palette: click the field, press the Down Arrow key for the list, or press ⌘1 to ⌘9 for the palettes listed, ⌘0 for General. Typing a new name makes a new palette.
  3. Optionally type a forced alias.
  4. Read Keys this would change, if it is shown: it lists the triggers whose keys the new one would move.
  5. Press Return to add, or Escape to cancel.

In the editor

  1. Select a palette in the sidebar.
  2. Choose File > New Trigger (⌘N), or click New Trigger in the toolbar.
  3. Type the name and the link in the new row.

File > New Trigger from Shortcut lists the Shortcuts on this Mac and makes a trigger for the one chosen.

From other apps

A link, an action in the Shortcuts app, a bookmark in a browser and an AI assistant can all add triggers. See Automation and AI Assistants.

Triggers That Ask for Input

A link can contain input fields, written as a name in braces. Picking such a trigger asks for the text first and puts it into the link.

https://www.youtube.com/results?search_query={Search}

This turns one trigger into a search of a website, or passes text to a Shortcut or a macro. The Automation page describes input fields in full.

New and Changed Marks

A trigger that did not come from the keyboard of the person using the Mac is marked until it has been opened once from the overlay.

NewAdded by an import, a shared palette, an action in the Shortcuts app that adds without asking, or an AI assistant.
ChangedIts link was changed by an import or an AI assistant.
  • The mark is a reminder to look at what the trigger opens before relying on it.
  • A link or an action from another app does not open a marked trigger by itself; it shows the trigger instead.
  • Triggers added in Quick Add or in the editor are not marked.
  • Settings > Overlay > Show New and Changed marks hides the tags in the overlay. The marks themselves stay, and so does the rule above.

When a Trigger Cannot Be Opened

If a link cannot be opened, a notice in the middle of the screen says which trigger and why: no app on the Mac opens that kind of link, the file is no longer at its path, Rapidfire has no access to the folder, or the drive is not connected. The notice goes away by itself and never takes the keyboard.

  • Automation: Rapidfire works with other tools on the Mac. Other apps can show a palette, add triggers, and read what is kept in Rapidfire, through links, through the Shortcuts app, and by dragging and copying.
  • AI Assistants: An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.
  • Files and iCloud Sync: Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.
  • How Keys Work: Rapidfire works out the keys for every trigger from its name. This page explains the rule, how to steer it with aliases, and how to lock the keys of a trigger so they never change.
