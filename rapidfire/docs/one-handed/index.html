Rapidfire Help

One-Handed Use

Rapidfire can be used with one hand on the keyboard, for working with the other on a mouse or trackpad, and for anyone who types with one hand. The keys of one half of the keyboard are mirrored onto the other.

Last updated 23 November 2026

How Mirroring Works

In Left Hand mode, every key of the right half of the keyboard is typed with its mirror key on the left: the same finger, the same row, the opposite hand. J becomes F, K becomes D, I becomes E. Right Hand mode is the reverse.

  • Names and their highlighted letters stay the same. Where the letter to type is on the other half, the key to press is shown raised beside it.
  • Typing the original letter still works.
  • Where a letter and its mirror would both be possible at the same place, Rapidfire uses one more letter, so keys never become ambiguous.
  • Mirroring follows the physical positions of keys, so it works with any keyboard layout.

Open the Overlay in a Hand Mode

  1. Open Settings > Hotkeys.
  2. In the empty row, choose the palette, then Left Hand or Right Hand.
  3. Click Record Shortcut and press a shortcut that the same hand can reach.

A palette can have a hotkey for each mode. Each hotkey always opens the same palette in the same mode.

Switch Hands in the Overlay

KeysWhat they do
⌘1Left hand.
⌘2Both hands.
⌘3Right hand.

The hand switcher at the top right of the overlay shows the mode and can be clicked. A switch lasts until the overlay closes; the next opening uses the hotkey’s own mode.

Settings for One-Handed Keys

Both are in Settings > Keys. The editor’s Left Hand and Right Hand columns show every trigger’s keys in each mode.

Locked keys are typed as their mirror keys in a one-handed mode, and the original letters still work.

  • How Keys Work: Rapidfire works out the keys for every trigger from its name. This page explains the rule, how to steer it with aliases, and how to lock the keys of a trigger so they never change.
  • Accessibility: Rapidfire is built to be used with VoiceOver, Voice Control, Switch Control, a keyboard alone, one hand, low vision, and without relying on color, motion or sound. This page lists what it does for each and which settings help.
  • Palettes: Palettes group triggers. A palette can have its own hotkeys, a prefix, and a place inside other palettes, which is how a large library stays easy to pick from.
