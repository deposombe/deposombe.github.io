What Rapidfire Can Do

A tour of Rapidfire’s features, from the keys it works out by itself to the AI assistant that can build a library while it is being watched. Each part points to the page that describes it in full.

Last updated 23 November 2026

Keys Without Setup

Most launchers ask for a name to be remembered and typed. Rapidfire shows everything and marks, in each name, the letters that tell it apart. No key is assigned by hand, and nothing has to be recalled: the keys are read off the screen until the fingers know them.

  • Two or three keys reach a trigger among hundreds.
  • The same names always give the same keys, on every Mac.
  • A trigger opens the moment it is the only one left. There is no Return to press.
  • How Keys Work: Rapidfire works out the keys for every trigger from its name. This page explains the rule, how to steer it with aliases, and how to lock the keys of a trigger so they never change.
  • The Overlay: The overlay is the list a hotkey shows. This page describes what is on it, every way of picking from it, and the modes that change how it behaves: Show All, watching, and opening a whole palette.

A Library That Stays Manageable

  • Palettes group triggers, and any palette can be shown inside any other, as its triggers after a prefix or as a single folder row.
  • Prefixes chain, so “a h Lights” is Lights in Home Assistant in Automations, reached with three letters.
  • Every palette can have its own hotkeys, and one hotkey can step through several palettes.
  • Show All opens every folder in place, so the whole library is on screen at once.
  • A dynamic palette shows a different palette depending on the time, the network or the app in front.
  • Palettes: Palettes group triggers. A palette can have its own hotkeys, a prefix, and a place inside other palettes, which is how a large library stays easy to pick from.
  • Automation: Rapidfire works with other tools on the Mac. Other apps can show a palette, add triggers, and read what is kept in Rapidfire, through links, through the Shortcuts app, and by dragging and copying.

Habits Are Protected

A launcher that is used by habit must not move things. Rapidfire treats the keys of a trigger as something to keep.

  • Before a trigger is added, Quick Add lists the triggers whose keys it would change, most used first.
  • Locked keys reserve exact keys for one trigger. Nothing added later can take or move them.
  • A forced alias gives a trigger a second, shorter name for keys.
  • Tab opens the most used trigger in the list.
  • Every change can be undone, including those made by an AI assistant or an import.
  • How Keys Work: Rapidfire works out the keys for every trigger from its name. This page explains the rule, how to steer it with aliases, and how to lock the keys of a trigger so they never change.
  • The Editor: The editor is the window in which the library is arranged: palettes on the left, the triggers of the selected palette in a table, and the palette’s settings at the side.

One Hand Is Enough

With one hand on the mouse, half the keyboard is out of reach. In Left Hand or Right Hand mode, every key of the far half is typed with its mirror key: the same finger and the same movement on the other hand. Names and highlighted letters stay as they are.

  • One-Handed Use: Rapidfire can be used with one hand on the keyboard, for working with the other on a mouse or trackpad, and for anyone who types with one hand. The keys of one half of the keyboard are mirrored onto the other.

Anything with a Link

  • Web pages, apps, files and folders, Shortcuts, BetterTouchTool and Keyboard Maestro actions, System Settings panes, and items in any app that has links.
  • A link can ask for text first: one trigger searches a website, or hands text to a Shortcut or a macro.
  • Holding Control opens a whole palette at once: every dashboard of a morning check, every tool of a project.
  • Adding is a drag onto the menu bar icon.
  • Triggers: A trigger is a name and a link. This page lists what a trigger can open, the ways of adding one, and what the marks next to a trigger mean.
  • Automation: Rapidfire works with other tools on the Mac. Other apps can show a palette, add triggers, and read what is kept in Rapidfire, through links, through the Shortcuts app, and by dragging and copying.

Built to Be Run by an AI Assistant

Rapidfire has an MCP server, so an AI assistant can read and rearrange the library on request: build a palette for a new project, shorten names without disturbing the keys used most, find duplicates.

  • An assistant can try a change first and see which keys it would move.
  • Every change is recorded with its old and new value and can be reverted.
  • What an assistant adds or changes is marked until it has been opened once.
  • The overlay can be watched while the assistant works: triggers appear as they are added.
  • The server runs on this Mac only, is off until switched on, and switches itself off when idle.
  • AI Assistants: An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.
  • Watching and Presenting: The overlay can be kept open, redrawn as the library changes, and unfolded to show everything at once. Together with a few links and settings, this makes it possible to follow an AI assistant at work, and to demonstrate or record Rapidfire without touching the keyboard.

Part of the Mac

  • Palettes and triggers are found by name in Spotlight, and asked for through Siri.
  • Actions in the Shortcuts app open, run, find and add triggers, also on a schedule or when a network is joined.
  • Every palette and trigger has a link, so a gesture, a Stream Deck key, a macro or a voice command can open it.
  • The overlay never takes over: it does not become the active app, and the app in front keeps its place.
  • Rapidfire follows the Mac’s appearance, accent color and accessibility settings in every window.
  • Spotlight and Siri: Palettes and triggers can be found by name in Spotlight and asked for through Siri, without opening Rapidfire first.
  • Automation: Rapidfire works with other tools on the Mac. Other apps can show a palette, add triggers, and read what is kept in Rapidfire, through links, through the Shortcuts app, and by dragging and copying.

Shared, Synced and Backed Up

  • A palette is shared as a file or as a link that can be read before it is opened.
  • Nothing is imported unseen: the Import window lists what every trigger does.
  • A team can post new versions of a palette; Rapidfire says whether an incoming one is newer or older, and updates without touching what was added locally.
  • iCloud keeps the library the same on every Mac, combining changes made on different Macs.
  • Copies of the library are kept before every change that removes much, and one command restores any of them.
  • Sharing and Backups: Palettes can be given to other people as a file or as a link, and the whole library can be saved and restored. Rapidfire also keeps its own copies before any change that removes much.
  • Files and iCloud Sync: Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.

Usable by Everyone

Every row is named for VoiceOver with its key. Everything works from the keyboard alone, with Voice Control and with Switch Control. Text size, row size and key style are adjustable, contrast meets WCAG AA, and nothing depends on color, motion or sound alone.

  • Accessibility: Rapidfire is built to be used with VoiceOver, Voice Control, Switch Control, a keyboard alone, one hand, low vision, and without relying on color, motion or sound. This page lists what it does for each and which settings help.
  • Keyboard Shortcuts: Every key Rapidfire uses, on one page. The menu bar icon’s menu opens this page directly: Control-click the icon and choose Keyboard Shortcuts.

Private by Design

Rapidfire has no account and no analytics. It connects to the internet only to look for a newer version of itself and to confirm a license key, when one has been entered. The library is two plain files on the Mac, synced only through the iCloud account of the person using it.
