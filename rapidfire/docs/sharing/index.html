Sharing and Backups

Palettes can be given to other people as a file or as a link, and the whole library can be saved and restored. Rapidfire also keeps its own copies before any change that removes much.

Last updated 22 November 2026

Share a Palette Import a Palette Save and Restore the Whole Library Backups Rapidfire Keeps

Share a Palette

A shared palette travels with the palettes shown inside it and with how they are nested.

As a file

  1. In the editor, select the palette and choose File > Export Palette, or Control-click it and choose Export Palette.
  2. Save the file and send it: AirDrop, a message, a shared folder.

Double-clicking the file on a Mac with Rapidfire opens the Import window.

As a link

  1. Control-click the palette and choose Copy Sharing Link.
  2. Paste the link into a message or a page.

The link contains the palette in readable form, one line per trigger, so it can be checked before it is opened. Where a link of this kind is not clickable, paste it into a browser’s address bar, or choose File > Import from Link in Rapidfire.

Only some triggers

File > Export Chosen Triggers shows the library as a list to tick: whole palettes or single triggers. What is ticked is saved as a file or copied as a link.

Hotkeys, locked keys and usage counts are never included in a shared palette. File triggers are shared as paths, which work for the receiver only if the file is at the same path.

Import a Palette

Nothing is ever imported or opened without being shown first. The Import window lists every trigger with what it does: opens a web page, runs a Shortcut, runs a macro, opens a file.

  1. Open the file or the link, or choose File > Import Palettes.
  2. Read the list. Untick anything unwanted.
  3. Choose where the palettes go: as new palettes, or inside an existing one.
  4. Click Import.
  • Imported triggers are marked New until each has been opened once.
  • An import adds palettes. It never merges into, replaces or deletes palettes already in the library, unless Update is chosen for a palette that was imported before.
  • The whole import is one step for Edit > Undo.

A newer version of a palette already imported

Rapidfire recognizes a palette it has imported before and says whether the incoming version is the same, newer or older. Update applies the sender’s changes: new triggers are added, renames and changed links are applied, and triggers added locally are left alone. Add as New keeps both.

An older version is pointed out in red, since importing it would undo newer changes.

Save and Restore the Whole Library

  1. Choose File > Export Library and save the file. It holds every palette, trigger and hotkey, and the settings.
  2. To bring it back, on this Mac or another, choose File > Restore Library and choose the file.

Restore replaces the whole library with the one in the file. Also restore settings, on by default, brings the settings back as well. Restore asks before it replaces anything, and Edit > Undo takes it back.

Backups Rapidfire Keeps

Rapidfire saves a copy of the library before a restore, before an import, when iCloud sync is switched on, and before sync changes or removes many items at once. The copies are kept on this Mac for 30 days.

  • File > Restore Library lists these copies with their dates.
  • File > Show Backups in Finder opens the folder they are in.
  • Backups are not synced and never leave the Mac.
  • Files and iCloud Sync: Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.
  • Triggers: A trigger is a name and a link. This page lists what a trigger can open, the ways of adding one, and what the marks next to a trigger mean.
  • AI Assistants: An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.
