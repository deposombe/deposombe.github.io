License

Rapidfire works without a license with the General palette. A license, bought once, adds more palettes and everything built on them, on 3 Macs.

With and Without a License

Without a licenseThe General palette, complete and without limits: any number of triggers, Quick Add, the editor, Spotlight and Siri, Shortcuts, links, iCloud sync and the MCP server.
With a licenseMore palettes, each with its own hotkeys; palettes shown inside other palettes as folders or with a prefix; dynamic palettes; the cycle; shared palettes imported as palettes; opening a whole palette at once.

Without a license, everything that needs one is shown with a padlock. Choosing it opens Settings > License. Nothing appears on its own: there are no reminders and no time limit. Only a license key that is on the Mac and has stopped counting is announced (see When Palettes Are Locked).

What is imported without a license, such as a shared palette or several links dropped at once, is added to General as plain triggers.

Buy a License

  1. Choose Buy Rapidfire from the menu bar icon’s menu, or in Settings > License. Rapidfire’s page on deposombe.com opens.
  2. Follow the Buy link. The purchase is made with Polar, the company that sells Rapidfire and sends the receipt.
  3. The license key arrives by email from Polar, and is also shown in Polar’s customer portal.

Enter a License Key

  1. Open Settings > License. License in the menu bar icon’s menu opens the same pane.
  2. Paste the key into License key and click Activate. The Mac must be online for this step.
  3. Status changes to Licensed, and the padlocks are gone.

One license works on 3 Macs. Each Mac on which the key is activated takes one of the three places.

Move a License to Another Mac

  1. On the Mac that no longer needs it, open Settings > License and click Remove License. The Mac must be online, so that its place is given back.
  2. On the other Mac, enter the key as described above.

When the old Mac is not at hand, its place is freed in Polar’s customer portal, under the email address used for the purchase. Settings > License shows each Mac’s name at the license server (This Mac), so the right one can be told apart.

A license is tied to the Mac on which the key was activated. On a Mac set up with Migration Assistant or from a backup of another Mac, Settings > License shows No license: enter the key there again. It takes one of the three places.

How the License Is Confirmed

  • About once a day while it runs, Rapidfire asks Polar’s license server whether the key still holds. The key, this Mac’s name at the license server (the word Mac and a random number, never the Mac’s own name) and Rapidfire’s two identifiers at Polar are sent. Nothing about palettes, triggers or files is sent.
  • A confirmation counts for 30 days. A Mac that is offline, or a license server that cannot be reached, changes nothing during that time.
  • When the license server has not been reached for more than three weeks, the menu bar icon shows a dot and its menu starts with License Server Not Reached, which opens Settings > License. The pane names the day on which palettes lock unless the server is reached. A firewall or a network filter that blocks api.polar.sh is the usual cause.
  • A refusal counts only when it comes from Polar’s license server itself, and only after it has been given twice. An error page from a network, a proxy or a filter changes nothing.
  • The key is kept in the Mac’s Keychain and tied to that Mac. The Mac’s hardware identifier is used for this on the Mac itself; it is not stored and never sent.
  • Without a license key, nothing is sent to Polar.

When Palettes Are Locked

No licenseNo key has been entered on this Mac.
License not validThe license server no longer accepts the key for this Mac: the purchase was refunded, or this Mac was removed in the customer portal. Check Again asks once more; Remove License clears the key so that it, or another, can be entered.
License not confirmedThe license has not been confirmed for 30 days. It is confirmed again, with nothing to enter, as soon as the Mac reaches the license server; Check Again asks at once. If the Mac is online, check that no firewall or network filter blocks api.polar.sh.
License not readableThe Keychain did not hand over the license kept on this Mac. Rapidfire reads it again by itself, and Check Again reads it at once. Nothing has to be entered again.

With a license key on the Mac, a lock is never silent. The menu bar icon shows a dot, and its menu starts with a line that names the state (License Not Valid, License Not Confirmed or License Not Readable) and opens Settings > License. The hotkeys of the locked palettes stay registered, and pressing one opens Settings > License as well. After Remove License there is no key, nothing is announced, and those hotkeys are no longer registered.

A palette that is locked is not deleted. It is listed in the editor with a padlock, stays in the library, in backups and in iCloud sync, and works again once the Mac has a license. Until then the overlay shows the General palette’s own triggers, and without a license key a locked palette’s hotkeys are not registered. A locked palette can be deleted, and Export Library and Restore Library work as always.

A Lost Key, Refunds and Invoices

  • A lost key is in the email from Polar and in Polar’s customer portal: Open Customer Portal in Settings > License.
  • Refunds are given within 14 days of the purchase, with no reason needed: write to support@deposombe.com from the email address used to pay.
  • Polar sends the receipt and issues invoices from the customer portal.
  • Settings: Every setting, pane by pane, with what it changes. Settings opens with ⌘, from the overlay, the editor and the menu bar icon’s menu.
  • Palettes: Palettes group triggers. A palette can have its own hotkeys, a prefix, and a place inside other palettes, which is how a large library stays easy to pick from.
