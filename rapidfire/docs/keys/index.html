How Keys Work

Rapidfire works out the keys for every trigger from its name. This page explains the rule, how to steer it with aliases, and how to lock the keys of a trigger so they never change.

Last updated 20 November 2026

The Rule When Keys Change Aliases Locked Keys Names No Key Can Tell Apart See Also

The Rule

Keys are never assigned by hand. Rapidfire compares the names that are still in the list, letter by letter, and highlights the first letter in which they differ. Typing that letter narrows the list, and the comparison repeats on what is left.

  • Instagram and Itch both start with i, so that letter says nothing. The next letters differ: n opens Instagram, t opens Itch.
  • Upper and lower case, and accents, are the same key: Ż, ż and z are all typed as z.
  • The end of a name counts as a Space. With “ab Notes” and “abc Blur” in the list, Space picks the first.
  • Letters, digits, punctuation and Space can all be keys. Emoji are shown but are never keys.
  • Symbols typed with Option are keys as well, and an accented letter typed with Option matches the plain letter in a name.

The rule is the same in every palette, and it always gives the same keys for the same set of names.

When Keys Change

Keys follow names. Adding, renaming, moving or deleting a trigger can change the keys of others in the same list, because the first differing letter may no longer be the same.

  • Quick Add shows the keys a new trigger would change before it is added, with how often each of those triggers is used.
  • The editor shows every trigger’s current keys in the Keys column, and its keys in each one-handed mode in the Left Hand and Right Hand columns.
  • An AI assistant that changes the library through MCP is told which keys moved after every change.

Aliases

A forced alias is a second, shorter name used for keys. The trigger can then be reached by its name or by its alias, and the alias is shown as a tag before the name.

  1. In the editor, click the trigger’s cell in the Alias column.
  2. Type the alias, for example dc for Discord, and press Return.

An alias suits a family of triggers that share a start: “dc” for Discord itself, and “dc gaming”, “dc work” for its servers. Typing d and c, then Space, opens Discord; another letter narrows to a server.

An alias is another name, not a reservation. Its keys are worked out by the same rule and can change when names change. For keys that never change, lock them.

Locked Keys

Locked keys are exact keys kept for one trigger. Typing them opens that trigger at once, in every list it appears in, whatever is added or renamed later. No other trigger can use them or keys that begin with them.

Lock the keys of a trigger

  1. In the editor, find the trigger and click its cell in the Locked Keys column. To lock the keys it has now, Control-click the row and choose Lock Current Keys instead.
  2. Type the keys and press Return.
  3. A window shows the keys in each hand mode and every other trigger whose keys would move. Confirm to lock.
  • A trigger with locked keys keeps the keys its name gives as well; both open it.
  • Locked keys must be unique in the whole library, in every hand mode. Keys that would clash are refused, with the reason.
  • Locked keys stay with the trigger when it moves to another palette and when a palette is shown somewhere else.
  • The editor’s sidebar has a Locked Triggers list with every trigger that has locked keys.
  • Locked keys follow iCloud sync and backups. They are not included when a palette is shared, since they could clash with the receiver’s.
  • Locked keys are set only in the editor. An AI assistant can see them but cannot set or remove them.

Names No Key Can Tell Apart

Two triggers with the same name have no letter in which they differ. When only such rows are left, the overlay says so and shows which palette each is in. Pick one with the arrow keys and Return, or click it. Renaming one of them, or giving it an alias, gives each its own keys.

Names written with an input method (Chinese, Japanese, Korean) cannot be typed in the overlay. Such triggers are picked with the arrow keys or the pointer, or given an alias in Latin letters.
