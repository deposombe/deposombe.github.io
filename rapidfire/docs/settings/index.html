Rapidfire Help

Settings

Every setting, pane by pane, with what it changes. Settings opens with ⌘, from the overlay, the editor and the menu bar icon’s menu.

Last updated 25 November 2026

General

Open at loginStarts Rapidfire when the Mac starts. Off until it is turned on. Kept per Mac.
Check for updates automaticallyOnce a day Rapidfire asks deposombe.com whether a newer version exists. On until it is turned off. A version that is found is offered as the first item of the menu bar icon’s menu, with a dot on the icon; it is downloaded and installed only after it is confirmed. Check for Updates asks at once, here and in the menu bar icon’s menu.
Download and install updates automaticallyUpdates are downloaded in the background and installed when Rapidfire is next quit, without asking. Off until it is turned on.
Offer to send a report after a crashIf Rapidfire quits unexpectedly, the next time it opens it offers to send a crash report by email. On until it is turned off; off, Rapidfire keeps no crash records at all. Kept per Mac. Report a Problem opens the same window for any other problem. See Troubleshooting and Privacy.
Count how often triggers are usedKeeps a count per trigger for the last 30 days, on this Mac only. It is what Tab in the overlay and the warnings about changed keys rely on. Turning it off deletes the counts; Clear Usage deletes them and keeps counting.
Show palettes and triggersWhether Spotlight, Siri and the Shortcuts app can find palettes and triggers by name.
When Find matches a triggerWhat “Find … in Rapidfire” does when one trigger matches: Show Its Palette or Run the Trigger.
When Find matches a paletteThe same for one palette: Show Its Overlay or Run the Whole Palette.
Links that run a triggerNew Key makes a new key for links that run a trigger or a palette. Links copied before then stop running anything and only show it.
Menu bar itemHow Rapidfire appears in the menu bar: Icon Only, Icon and “RF”, or Icon and “Rapidfire”. A wider item is easier to hit.

Hotkeys

Every palette’s hotkeys in one list. Each row has a hand mode and a shortcut; the empty row at the end adds one. The same rows are in each palette’s Palette Settings in the editor.

  • Palettes: Palettes group triggers. A palette can have its own hotkeys, a prefix, and a place inside other palettes, which is how a large library stays easy to pick from.
  • One-Handed Use: Rapidfire can be used with one hand on the keyboard, for working with the other on a mouse or trackpad, and for anyone who types with one hand. The keys of one half of the keyboard are mirrored onto the other.

Overlay

Layout

LayoutExpanded (columns) adds columns as the list grows. Collapsed (one list) is a single scrolling list that can be resized by dragging its edges.
OpensCenter of the Screen, on the screen the pointer is on, or At the Pointer. A palette can have its own choice.
Maximum width, Maximum heightThe largest the overlay may be, as a share of the screen: Small, Medium, Large, Extra Large or Full Screen. The overlay is only as big as its contents need.
Lines between columnsA thin line between the overlay’s columns. It takes no room: the columns stay where they are.

Show All

Open in Show AllOpens the overlay with its folders already opened, for palettes that open in the center of the screen. A palette that opens at the pointer always opens closed.
ShowEverything shows every trigger and folder inside the opened folders. Folders Only shows only the folders inside them, each with how many triggers it holds at any depth, so the shape of a large library fits on one screen. The palette that is showing keeps its own triggers in both.
Open foldersEvery Level opens folders inside folders too. One Level opens only the folders of the palette that is showing, and shows the folders inside them closed.
Bold folder namesWhich folder names are bold in Show All: None, Top Level (the folders of the palette that is showing, the ones Show All opens first), or All Folders (every folder, opened or closed). The overlay with its folders closed does not change.
Folder weightHow bold those folder names are: Semibold or Bold.
Maximum sizeThe largest Show All’s opened view may be. It is separate from the sizes above, so the everyday overlay can stay small.
Shrink text to fitWhen the opened view is larger than its maximum size, makes its text smaller, down to the smallest text size, before it scrolls.

Items

Text sizeThe size of the names. ⌘+ and ⌘− in the overlay change the same setting; ⌘0 resets it.
Item sizeThe space around each row: Small, Medium or Large. Larger rows are easier to click or tap.
Long namesWhere long names are cut: Show Full Names, Long, Medium or Short. A name is never cut before its key.
Key styleHow the key letters are marked: Underline, Box, or Color (the accent color with no underline). Box is used automatically when Differentiate Without Color is on.
LookStandard draws the overlay as it always was: see-through, with names blended into its background. Balanced keeps it see-through, with a tint that keeps what is behind from washing it out; folder names are crisp and trigger names a step quieter, so the groups stand out. Studio gives the overlay a solid panel, off-white or graphite with a soft gradient, and the same crisp folders and quieter triggers. Balanced and Studio keep every name readable over any background. All three follow Light, Dark and Increase Contrast; keys and tags stay in the accent color.
FontThe overlay’s typeface: System, or Rounded (the system’s rounded design). Aliases and locked keys stay in a fixed-width font.
Show New and Changed marksShows the New and Changed tags in the overlay. Off hides the tags there; the marks are kept, and marked triggers are still not run by links or actions.
Mark styleTag shows the word New or Changed. Dot shows a filled dot for New and an orange ring for Changed; pointing at it says which. The words are used automatically when Differentiate Without Color is on.
Folder countsWhich folders show how many triggers they hold, at any depth: None, Closed Folders, or All Folders. Show All’s Folders Only counts every folder in either case.
Pointer styles move with Reduce Motion onLets pointer styles that move, chosen with ⌘] and ⌘[ in the overlay, move also while Reduce Motion is on in System Settings. Off, such a style is shown as Quiet.

Keys

A key that matches nothingCloses the Overlay, or Is Ignored. When ignored, the overlay shakes; with Reduce Motion on, it plays the alert sound and shows a line saying so.
Open the last itemInstantly opens a trigger as soon as it is the only one left. After Pressing Return keeps it highlighted until Return.
Confirm before opening manyWhen opening a whole palette asks first: Never, Over 10 Triggers, or Always. It applies to holding Control in the overlay, to links that run a palette, and to Run Palette in Shortcuts and Siri. The overlay asks in place of the list; Shortcuts and Siri ask in their own window.
Bottom rowFor one-handed modes: whether bottom-row keys mirror by movement or by finger.
Show the key to pressFor one-handed modes: Next to the Letter, or Column on the Left.

Files

The folders, files and drives that file triggers may be opened from, with Add Folder or File and Give Access to Your Home Folder. Kept per Mac.

  • Files and iCloud Sync: Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.

Sync

Sync with iCloud, the Macs that sync, what was received from them, and Copy Sync Report.

  • Files and iCloud Sync: Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.

MCP

The MCP server’s switch, Turn off after, the address and the port, the token, the setup command for Claude Code, and the activity of the last 30 days.

  • AI Assistants: An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.

License

Whether this Mac has a license, the field for a license key with Activate, Buy Rapidfire, and, with a license, the key, this Mac’s name at the license server, when the license was last confirmed, and Remove License. Choosing anything with a padlock opens this pane.

  • License: Rapidfire works without a license with the General palette. A license, bought once, adds more palettes and everything built on them, on 3 Macs.

Which Settings Sync

With iCloud sync on, the settings of the Overlay and Keys panes, and the choices under Siri and Spotlight, are the same on every Mac. Open at login, the crash report setting, the usage counts, Files, and everything in the MCP pane stay on each Mac.
