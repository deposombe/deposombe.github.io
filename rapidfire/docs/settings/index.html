Rapidfire Help

Settings

Every setting, pane by pane, with what it changes. Settings opens with ⌘, from the overlay, the editor and the menu bar icon’s menu.

Last updated 20 November 2026

General Hotkeys Overlay Keys Files Sync MCP Which Settings Sync

General

Open at loginStarts Rapidfire when the Mac starts. Off until it is turned on. Kept per Mac.
Count how often triggers are usedKeeps a count per trigger for the last 30 days, on this Mac only. It is what Tab in the overlay and the warnings about changed keys rely on. Turning it off deletes the counts; Clear Usage deletes them and keeps counting.
Show palettes and triggersWhether Spotlight, Siri and the Shortcuts app can find palettes and triggers by name.
When Find matches a triggerWhat “Find … in Rapidfire” does when one trigger matches: Show Its Palette or Run the Trigger.
When Find matches a paletteThe same for one palette: Show Its Overlay or Run the Whole Palette.
Links that run a triggerNew Key makes a new key for links that run a trigger or a palette. Links copied before then stop running anything and only show it.
Menu bar itemHow Rapidfire appears in the menu bar: Icon Only, Icon and “RF”, or Icon and “Rapidfire”. A wider item is easier to hit.

Hotkeys

Every palette’s hotkeys in one list. Each row has a hand mode and a shortcut; the empty row at the end adds one. The same rows are in each palette’s Palette Settings in the editor.

  • Palettes: Palettes group triggers. A palette can have its own hotkeys, a prefix, and a place inside other palettes, which is how a large library stays easy to pick from.
  • One-Handed Use: Rapidfire can be used with one hand on the keyboard, for working with the other on a mouse or trackpad, and for anyone who types with one hand. The keys of one half of the keyboard are mirrored onto the other.

Overlay

Layout

LayoutExpanded (columns) adds columns as the list grows. Collapsed (one list) is a single scrolling list that can be resized by dragging its edges.
OpensCenter of the Screen, on the screen the pointer is on, or At the Pointer. A palette can have its own choice.
Maximum width, Maximum heightThe largest the overlay may be, as a share of the screen: Small, Medium, Large, Extra Large or Full Screen. The overlay is only as big as its contents need.

Show All

Maximum sizeThe largest the view with every folder opened may be. It is separate from the sizes above, so the everyday overlay can stay small.
Shrink text to fitWhen the opened view is larger than its maximum size, makes its text smaller, down to the smallest text size, before it scrolls.

Items

Text sizeThe size of the names. ⌘+ and ⌘− in the overlay change the same setting; ⌘0 resets it.
Item sizeThe space around each row: Small, Medium or Large. Larger rows are easier to click or tap.
Long namesWhere long names are cut: Show Full Names, Long, Medium or Short. A name is never cut before its key.
Key styleHow the key letters are marked: Underline or Box. Box is used automatically when Differentiate Without Color is on.
Show New and Changed marksShows the New and Changed tags in the overlay. Off hides the tags there; the marks are kept, and marked triggers are still not run by links or actions.
Pointer styles move with Reduce Motion onLets pointer styles that move, chosen with ⌘] and ⌘[ in the overlay, move also while Reduce Motion is on in System Settings. Off, such a style is shown as Quiet.

Keys

A key that matches nothingCloses the Overlay, or Is Ignored. When ignored, the overlay shakes; with Reduce Motion on, it plays the alert sound and shows a line saying so.
Open the last itemInstantly opens a trigger as soon as it is the only one left. After Pressing Return keeps it highlighted until Return.
Confirm before opening manyWhen holding Control opens a whole palette: Never, Over 10 Triggers, or Always ask first.
Bottom rowFor one-handed modes: whether bottom-row keys mirror by movement or by finger.
Show the key to pressFor one-handed modes: Next to the Letter, or Column on the Left.

Files

The folders, files and drives that file triggers may be opened from, with Add Folder or File and Give Access to Your Home Folder. Kept per Mac.

  • Files and iCloud Sync: Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.

Sync

Sync with iCloud, the Macs that sync, what was received from them, and Copy Sync Report.

  • Files and iCloud Sync: Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.

MCP

The MCP server’s switch, Turn off after, the port, the setup command for Claude Code, the token, and the activity of the last 30 days.

  • AI Assistants: An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.

Which Settings Sync

With iCloud sync on, the settings of the Overlay and Keys panes, and the choices under Siri and Spotlight, are the same on every Mac. Open at login, the usage counts, Files, and everything in the MCP pane stay on each Mac.
