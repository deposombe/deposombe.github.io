Rapidfire Help

Troubleshooting and Privacy

What to check when something does not work as expected, where Rapidfire keeps its data, and what it does and does not do with it.

The Hotkey Does Nothing

  • Open Settings > Hotkeys. A row whose shortcut could not be registered says why, usually that another app uses it. Record a different shortcut.
  • On macOS 15.0 and 15.1, shortcuts that use only Option, or only Option and Shift, are not accepted. Add Command or Control.
  • A hotkey of a palette besides General that opens Settings > License: the license on this Mac does not count at the moment, and the pane says why. See License.
  • Check that Rapidfire is running: its icon is in the menu bar. If the menu bar is full, macOS hides icons; opening Rapidfire again from Applications or Spotlight shows the General palette.

A Trigger Does Not Open

The notice that appears says why. The usual reasons:

No app opens this kind of linkThe app the link belongs to is not installed, or the link is misspelled.
No accessA file or folder outside the locations in Settings > Files. Add its folder there.
Not at its pathThe file was moved, renamed or deleted. In the editor, Control-click the trigger and choose Locate.
Drive not connectedAttach the drive.

A Shortcut or a macro that does not run is usually renamed or disabled in its own app; the trigger’s link names it exactly.

The Keys of a Trigger Changed

Keys come from names, so a new or renamed trigger can move the keys of others. Quick Add and AI assistants report this before or when it happens.

  • To give a trigger keys that never change, lock them in the editor’s Locked Keys column.
  • To steer keys without locking, give the trigger a forced alias.
  • Edit > Undo takes the last change back, with the keys it moved.

A Link from Another App Shows a Trigger but Does Not Open It

  • A link opens a trigger by itself only when it contains the key made on this Mac. Copy it again with Copy Link to Trigger > That Runs It.
  • After New Key in Settings > General, links copied before only show the trigger.
  • A trigger marked New or Changed, and one that runs a program or an installer, is shown, not opened, until it has been opened once from Rapidfire.

An AI Assistant Cannot Connect

  • The server switches itself off when idle. Turn MCP Server on again in Settings > MCP or the menu bar icon’s menu.
  • After Regenerate, the assistant needs the new token.
  • After turning the server on, start a new conversation, so that the assistant reads the tools again.

The Menu Says to Move Rapidfire to the Applications Folder

Rapidfire was opened from its disk image, or from the Downloads folder without having been moved. From there it cannot install updates, and Open at Login stops working after a restart. The menu bar icon shows a dot, and its menu starts with Move Rapidfire to the Applications Folder.

  1. Quit Rapidfire: Quit Rapidfire in the menu bar icon’s menu.
  2. Drag Rapidfire to the Applications folder. The disk image has a shortcut to it.
  3. Open Rapidfire from the Applications folder. Triggers and settings are kept. If Open at Login was on, switch it off and on again in Settings > General.

Sync Is Not Catching Up

  • Settings > Sync says why sync is paused: iCloud signed out or full, a question waiting for an answer, or a Mac on an older version of Rapidfire.
  • A Mac whose date and time are more than a day off is not synced with. Correct the clock.
  • Copy Sync Report copies what a problem report needs, without names or links.

Something Was Lost

  1. Try Edit > Undo first.
  2. For a change made by an AI assistant, open MCP Activity, select the change and click Revert.
  3. Otherwise choose File > Restore Library and pick a copy from before the loss. Rapidfire keeps copies for 30 days.

Where Rapidfire Keeps Its Data

  • The library and the settings are two plain files in Rapidfire’s own folder on this Mac. File > Show Backups in Finder opens the folder with the saved copies next to them.
  • With iCloud sync on, each Mac also keeps one file in Rapidfire’s private iCloud folder.
  • The MCP token, the key for links that run triggers, and the license key are in the Keychain.

Privacy

  • Rapidfire collects nothing and sends nothing to its developer. It has no analytics and no account.
  • It connects to the internet for two things only. Once a day it asks deposombe.com whether a newer version exists, and downloads an update from GitHub when one is confirmed; this can be turned off in Settings > General. And a license key, when one is entered, is confirmed with Polar, the company that sells Rapidfire: the key and a random name for the Mac are sent. Neither sends anything about the library.
  • The MCP server accepts connections only from programs on this Mac.
  • iCloud sync, when on, stores the library in the iCloud account signed in on the Mac. Usage counts, backups and MCP activity never leave the Mac and are deleted after 30 days.
  • Rapidfire opens files only through the access given in Settings > Files, and only when a trigger is picked.
  • Links can hold private information, such as a document’s address. Rapidfire is not a place for passwords: anything in a link is stored as plain text.
  • Files and iCloud Sync: Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.
  • AI Assistants: An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.
  • Sharing and Backups: Palettes can be given to other people as a file or as a link, and the whole library can be saved and restored. Rapidfire also keeps its own copies before any change that removes much.
  • Accessibility: Rapidfire is built to be used with VoiceOver, Voice Control, Switch Control, a keyboard alone, one hand, low vision, and without relying on color, motion or sound. This page lists what it does for each and which settings help.
  • License: Rapidfire works without a license with the General palette. A license, bought once, adds more palettes and everything built on them, on 3 Macs.
