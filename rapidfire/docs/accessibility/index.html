Rapidfire Help

Accessibility

Rapidfire is built to be used with VoiceOver, Voice Control, Switch Control, a keyboard alone, one hand, low vision, and without relying on color, motion or sound. This page lists what it does for each and which settings help.

Last updated 21 November 2026

VoiceOver Keyboard Only Voice Control and Switch Control One Hand Vision Motion Hearing Language

VoiceOver

  • Every row of the overlay is read with its name and the key to type next: “Instagram, key N”. A folder says that it opens a palette, a trigger that asks for input says so, and a marked trigger says New or Changed.
  • After each key, VoiceOver says how many items are left.
  • With Show All on, a row inside an opened folder says which folder it is in.
  • Messages that appear in the overlay are spoken: why Tab did nothing, that no key tells the remaining rows apart, that a trigger could not be opened and why.
  • The overlay is announced by its palette’s name. The mark in its corner is decoration and is skipped.
  • In the editor, Settings and Help, headings are marked as headings, tables and switches have names, and buttons that show only an icon have a spoken name.
  • The menu bar icon has a Show Menu action, since VoiceOver has no gesture for a right-click there.

Keyboard Only

  • Everything in the overlay is done from the keyboard. The pointer is never needed.
  • The arrow keys move a highlight through the rows and Return opens it, for rows that keys cannot reach.
  • The editor, Settings and Help follow the Mac’s conventions: Tab and Shift-Tab between controls, Return for the default button, Escape to cancel, ⌘W to close, and a menu command for every action.
  • Keyboard navigation and Full Keyboard Access, set in System Settings, work in every window.
  • Keyboard Shortcuts: Every key Rapidfire uses, on one page. The menu bar icon’s menu opens this page directly: Control-click the icon and choose Keyboard Shortcuts.

Voice Control and Switch Control

Controls have the names they show, so “Click Add”, “Click Show All” and “Click Left Hand” work as spoken. Rows of the overlay are buttons named after their triggers. Switch Control reaches the same controls.

One Hand

Left Hand and Right Hand modes mirror the keys of one half of the keyboard onto the other, so every trigger can be typed with one hand.

  • One-Handed Use: Rapidfire can be used with one hand on the keyboard, for working with the other on a mouse or trackpad, and for anyone who types with one hand. The keys of one half of the keyboard are mirrored onto the other.

Vision

Text sizeSettings > Overlay, or ⌘+ and ⌘− in the overlay, from 11 to 32 points.
Item sizeLarger rows, for clicking or tapping.
Key styleBox puts the key letter in a filled box in place of an underline.
Maximum width and heightA larger overlay fits more columns at a large text size.
  • Text in every window meets the contrast of WCAG AA (4.5 to 1), in light and in dark appearance, and is stronger with Increase Contrast on.
  • The overlay’s background is solid, so its contrast does not depend on what is behind it.
  • Rapidfire follows the Mac’s appearance, accent color, Increase Contrast, Reduce Transparency and Differentiate Without Color. With Differentiate Without Color on, key letters are boxed, not only colored.
  • Zoom, Hover Text, Invert Colors and Color Filters work as in any app.

Motion

With Reduce Motion on in System Settings > Accessibility > Motion (Display on macOS 15), the overlay does not shake when a key is ignored, and the eye does not move when a watched overlay changes.

Pointer styles, chosen with ⌘] and ⌘[ in the overlay, follow Reduce Motion: a style that moves is shown as Quiet, the style a new installation uses, and the line that names the style says so. Settings > Overlay > Pointer styles move with Reduce Motion on lets them move.

Hearing

Rapidfire speaks nothing itself and uses only the Mac’s alert sound. Whatever the sound stands for is also shown.

  • A trigger that cannot be opened: a notice in the middle of the screen names the trigger and the reason.
  • Tab with no usage recorded: a line in the overlay says so.
  • A key that is ignored: the overlay shakes. With Reduce Motion on, a line in the overlay says that no trigger has that key.
  • Control held on a trigger in General, which cannot be opened as a whole palette: a line in the overlay says so.

To see the Mac’s alert sound itself, turn on Flash the screen when an alert sound occurs in System Settings > Accessibility > Audio.

Language

Rapidfire is in English. Names of triggers and palettes can be in any language and script; a key typed with an accent matches the plain letter in a name.
