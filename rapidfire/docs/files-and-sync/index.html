Files and iCloud Sync

Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.

Last updated 21 November 2026

Triggers That Open Files

A trigger for a file or a folder stores its path. The trigger opens whatever is at that path, when the path is inside a location listed in Settings > Files. Apps need no access: a trigger for an app always opens it.

Give access

  1. Open Settings > Files.
  2. Click Add Folder or File and choose a folder that holds the files, such as Documents or a project folder. To cover everything at once, click Give Access to Your Home Folder.

A file dropped onto Rapidfire is given access by the drop itself and appears in the list on its own.

Rapidfire opens only what triggers point to. It does not list, read or upload files in the folders it has access to. Access is kept per Mac and is not synced.

When a File Trigger Needs Attention

The editor shows an icon before the path of a file trigger that cannot be opened.

Needs accessThe path is outside the locations in Settings > Files. Control-click the trigger and choose Give Access.
MissingNothing is at the path any more: the file was moved, renamed or deleted. Control-click the trigger and choose Locate to point it at the file’s new place.
Drive not connectedThe path is on a drive that is not attached. The trigger works again when the drive is.

Rapidfire does not follow a file that is moved. This keeps the editor, a shared palette and another Mac all agreeing on what a trigger opens.

A file trigger works on every Mac on which the file is at the same path. Folders in iCloud Drive, Dropbox and similar services usually are.

iCloud Sync

With sync on, palettes, triggers, hotkeys and settings are the same on every Mac signed in to the same iCloud account.

  1. Open Settings > Sync.
  2. Turn on Sync with iCloud.
  3. Do the same on each other Mac.
  • Changes made on different Macs are combined: a trigger renamed on one Mac and given a new link on another keeps both changes.
  • A deleted trigger stays deleted, also on a Mac that was switched off for months.
  • Each Mac works on its own while iCloud is unavailable, and catches up afterwards.
  • The Macs list shows every Mac that syncs, when it last did, and its version of Rapidfire.

What Stays on Each Mac

  • Access to files and folders (Settings > Files).
  • Usage counts.
  • The MCP server’s switch, port, token and activity.
  • Open at login.
  • What each dynamic palette shows.
  • Backups and the sync log.

When Sync Asks a Question

Two different librariesA Mac that already has a library of its own is asked which one to keep: Use the iCloud Library or Use This Mac’s Library. The other is kept as a backup.
Many deletions at onceA change from another Mac that would remove many triggers is held back. Keep Mine keeps them and takes that Mac’s other changes; Apply lets the deletions happen.
A newer version of RapidfireA Mac running an older version stops syncing rather than write over what it does not understand. Updating Rapidfire on that Mac resumes sync.

A dot at the bottom left of the menu bar icon means sync is waiting for an answer; the first item of the icon’s menu opens Settings > Sync.

Remove a Mac

For a Mac that is no longer in use, click Forget next to it in Settings > Sync. A Mac that is still in use reappears the next time it syncs.

Copy Sync Report, in Settings > Sync, copies a description of the sync state without names or links, for reporting a problem.

  • Sharing and Backups: Palettes can be given to other people as a file or as a link, and the whole library can be saved and restored. Rapidfire also keeps its own copies before any change that removes much.
