Getting Started

Rapidfire keeps links, apps, files and automations in one list, shows the list with a hotkey, and opens an item after a few keys. This page covers the first five minutes.

What Rapidfire Does

Rapidfire is a launcher for the things that are too many for hotkeys and too easily forgotten for search: dashboards, documents, settings panes, macros, Shortcuts. Everything kept in it is called a trigger. A trigger has a name and a link, and opening the trigger opens the link.

Pressing a hotkey shows the triggers in an overlay. Each name has highlighted letters. Typing those letters narrows the list, and as soon as one trigger is left, it opens. The keys come from the names, so they are read from the screen at first and typed from memory later.

  • Triggers are grouped in palettes. The General palette is always there; more can be added and shown inside each other.
  • A trigger can be a web page, an app, a file or folder, a Shortcut, a BetterTouchTool or Keyboard Maestro action, a System Settings pane, or any other link an app on the Mac understands.
  • Rapidfire opens links. The work is done by the app the link belongs to.

Open the Overlay

A new installation starts with a small set of triggers and one hotkey, so it can be tried at once.

  1. Press Control-Option-Space. The overlay opens with the General palette. Clicking Rapidfire’s icon in the menu bar does the same.
  2. Type the highlighted letter of a trigger. The list narrows to the names that share it.
  3. Keep typing the highlighted letters until one trigger is left. It opens, and the overlay closes.

To close the overlay without opening anything, press Escape or press the hotkey again.

The hotkey is shown and changed in the Welcome window (Help > Welcome to Rapidfire) and in Settings > Hotkeys. If another app already uses Control-Option-Space, the hotkey’s row says so; record a different one there.

The Starter Triggers

A new installation is not empty. Its triggers work on every Mac and show what a library can hold.

SearchesGoogle Search, YouTube Search, Wikipedia Search and others ask for text and open the results. Translate and Define Word work the same way.
Calculator, Activity MonitorTwo of the Mac’s own apps.
Wi-Fi Settings, Bluetooth SettingsPanes of System Settings.
Rapidfire Help, Add TriggerLinks back into Rapidfire itself.

All of it can be renamed or deleted.

Add a Trigger

  1. Drag a link from a browser, a file or folder from Finder, or an app onto Rapidfire’s icon in the menu bar. While something is being dragged, a drop zone labeled Rapidfire appears under the icon; dropping there works too.
  2. Quick Add opens with the name and the address filled in. Change the name if a shorter one is easier to type.
  3. Choose a palette, or leave General, and press Return.

Quick Add lists the triggers whose keys the new name would change, most used first, so a habit is never broken without notice.

The Menu Bar Icon

  • Click the icon to open the General palette.
  • Control-click (or right-click) the icon for the menu: Open Editor, Settings, exporting and backups, the MCP server, Keyboard Shortcuts, Rapidfire Help, and Quit Rapidfire.
  • A small dot at the top right of the icon means the MCP server is on. A dot at the bottom left means iCloud sync, an update or the license needs attention; the first menu item then says why.

Rapidfire is a menu bar app: it has no Dock icon while only the overlay is in use. The Dock icon and the app’s own menus appear while the editor, Settings or Help is open.
