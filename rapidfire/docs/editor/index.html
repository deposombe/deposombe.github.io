The Editor

The editor is the window in which the library is arranged: palettes on the left, the triggers of the selected palette in a table, and the palette’s settings at the side.

Last updated 21 November 2026

Open the Editor The Sidebar The Table Find Copy, Paste and Drag Delete and Undo The MCP Button

Open the Editor

  • Control-click Rapidfire’s icon in the menu bar and choose Open Editor.
  • Press ⌘E in the overlay, in Settings or in Help.

While the editor is open, Rapidfire has a Dock icon and its own menus, and appears in the app switcher. Closing the window returns the keyboard to the app that was in front before.

The Sidebar

All TriggersEvery trigger in the library, with a Palette column that says where each one is. Searching here finds a trigger wherever it is kept.
Locked TriggersEvery trigger with locked keys.
General and the palettesOne row for each palette. A palette shown inside another is listed as usual; the Inside row above the table shows what the selected palette contains.

New Palette and New Dynamic Palette are at the bottom of the sidebar. Control-clicking a palette offers its commands, among them Rename, Copy Sharing Link, Export Palette, and the links that open or run the palette.

The Table

NameWhat the overlay shows and what the keys are made from.
AliasAn optional forced alias: a second name for keys.
URLThe link, or the path of a file. An icon before it shows a trigger that asks for input, or a file that needs attention.
Typed AsThe text the keys are worked out from: the name without emoji and accents, and the alias.
KeysThe keys that open the trigger now, with both hands.
Locked KeysKeys reserved for the trigger. Typing here asks before locking.
Left Hand, Right HandThe keys in each one-handed mode.
  • Click a cell to edit it. Return saves, Escape leaves it unchanged.
  • Click a column’s heading to sort by it.
  • Select several rows with Command-click or Shift-click.
  • Control-click a row for its commands, among them Copy, Copy Link to Trigger, and locking or unlocking its keys.

Find

Edit > Find > Find (⌘F) puts the cursor in the search field. Searching narrows the table to names, aliases and links that contain the text; in All Triggers it also matches a palette’s name.

Copy, Paste and Drag

  • ⌘C copies the selected triggers. They paste as named links into notes and messages, and as addresses into a browser.
  • ⌘V pastes links, files or copied triggers into the palette that is showing.
  • Drag triggers onto a palette in the sidebar to move them there.
  • Drag a trigger or a palette out of the window to put its link into another app.

Delete and Undo

Delete, ⌘Delete and Edit > Delete remove what was selected last, triggers or palettes, after asking. Inside a text field these keys only delete text.

Every change to the library can be undone with Edit > Undo (⌘Z) and redone with Edit > Redo (⇧⌘Z): edits in the editor, triggers added by Quick Add, imports, and changes made by an AI assistant. The menu item names the change it would undo.

Undo is refused, with the reason, when taking a change back would break a rule that has come into force since: for example, when the keys it would lock again now belong to another trigger.

The MCP Button

The toolbar’s MCP button shows whether the MCP server is on, switches it, and lists the latest changes made through it. See AI Assistants.

  • Palettes: Palettes group triggers. A palette can have its own hotkeys, a prefix, and a place inside other palettes, which is how a large library stays easy to pick from.
  • How Keys Work: Rapidfire works out the keys for every trigger from its name. This page explains the rule, how to steer it with aliases, and how to lock the keys of a trigger so they never change.
  • Sharing and Backups: Palettes can be given to other people as a file or as a link, and the whole library can be saved and restored. Rapidfire also keeps its own copies before any change that removes much.
  • AI Assistants: An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.
