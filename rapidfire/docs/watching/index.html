Watching and Presenting

The overlay can be kept open, redrawn as the library changes, and unfolded to show everything at once. Together with a few links and settings, this makes it possible to follow an AI assistant at work, and to demonstrate or record Rapidfire without touching the keyboard.

Watching

Normally the overlay closes as soon as another app takes the keyboard, and it shows the library as it was when it opened. A watched overlay does neither: it stays where it is, and it is drawn again after every change to the library, whoever made the change.

KeysWhat they do
⌘KSwitches watching on or off in the overlay that is open.
⌘TSwitches Show All on or off: every folder opened in place.
EscapeCloses the overlay, watched or not.

The eye and the Show All button in the overlay’s top row do the same for the pointer. Both modes end when the overlay closes.

Links That Open the Overlay in a Mode

The link that opens a palette takes two extra parts, so that a script, a macro or an AI assistant can set the overlay up.

watch=yesKeeps the overlay open and redraws it on every change. watch=no stops that.
all=yesOpens every folder in place. all=no closes them again.

rapidfire://open?watch=yes

rapidfire://open?all=yes

rapidfire://open?watch=yes&all=yes

rapidfire://open?palette=Dev&watch=yes

  • With either part, a palette that is already showing stays open and only changes how it shows. Without them, the link behaves like the palette’s hotkey and closes a palette that is showing.
  • The links only show things. They cannot add, change or open a trigger.
  • In Terminal, a link is opened with the open command, with the link in quotation marks.

open "rapidfire://open?watch=yes"

Follow an AI Assistant

  1. Turn on the MCP server and connect the assistant, as described in AI Assistants.
  2. Open the watched overlay: press the hotkey and then ⌘K, or open the first link above.
  3. Give the assistant its task. Each trigger appears in the overlay as it is added, and the eye moves with each change.
  4. Press ⌘T, or open the link with all=yes, to see the result with every folder opened.

An assistant can open these links itself when it has a way to open links on the Mac. Rapidfire’s MCP server lists them for it.

Prepare a Demonstration or a Recording

Show New and Changed marksSettings > Overlay. Turn it off to keep the tags off triggers an assistant has just added. The marks themselves are kept.
Maximum size (Show All)Settings > Overlay > Show All. The largest the opened view may grow: Extra Large leaves a margin around it, Full Screen uses nearly all of the screen.
Shrink text to fitSettings > Overlay > Show All. Makes the text of the opened view smaller, as far as needed, so that a large library fits without scrolling.
Text sizeSettings > Overlay, or ⌘+ and ⌘− in the overlay. Larger text reads better in a recording; a larger screen fits more at the same size.
OpensSettings > Overlay. Center of the Screen keeps the overlay in the same place from one opening to the next.

With Reduce Motion on in System Settings > Accessibility > Motion (Display on macOS 15), the eye does not move when a change arrives. The overlay is still redrawn.

  • AI Assistants: An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.
  • The Overlay: The overlay is the list a hotkey shows. This page describes what is on it, every way of picking from it, and the modes that change how it behaves: Show All, watching, and opening a whole palette.
  • Automation: Rapidfire works with other tools on the Mac. Other apps can show a palette, add triggers, and read what is kept in Rapidfire, through links, through the Shortcuts app, and by dragging and copying.
  • Settings: Every setting, pane by pane, with what it changes. Settings opens with ⌘, from the overlay, the editor and the menu bar icon’s menu.
