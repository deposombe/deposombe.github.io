Rapidfire Help

Rapidfire is a keyboard launcher for the Mac. It shows the links, apps and files kept in it, and opens one after a few keys. These pages describe everything it does. The same pages are in the app, under Help.

Last updated 21 November 2026

  • Getting Started
    Rapidfire keeps links, apps, files and automations in one list, shows the list with a hotkey, and opens an item after a few keys. This page covers the first five minutes.
  • What Rapidfire Can Do
    A tour of Rapidfire’s features, from the keys it works out by itself to the AI assistant that can build a library while it is being watched. Each part points to the page that describes it in full.
  • The Overlay
    The overlay is the list a hotkey shows. This page describes what is on it, every way of picking from it, and the modes that change how it behaves: Show All, watching, and opening a whole palette.
  • How Keys Work
    Rapidfire works out the keys for every trigger from its name. This page explains the rule, how to steer it with aliases, and how to lock the keys of a trigger so they never change.
  • Palettes
    Palettes group triggers. A palette can have its own hotkeys, a prefix, and a place inside other palettes, which is how a large library stays easy to pick from.
  • Triggers
    A trigger is a name and a link. This page lists what a trigger can open, the ways of adding one, and what the marks next to a trigger mean.
  • The Editor
    The editor is the window in which the library is arranged: palettes on the left, the triggers of the selected palette in a table, and the palette’s settings at the side.
  • One-Handed Use
    Rapidfire can be used with one hand on the keyboard, for working with the other on a mouse or trackpad, and for anyone who types with one hand. The keys of one half of the keyboard are mirrored onto the other.
  • Sharing and Backups
    Palettes can be given to other people as a file or as a link, and the whole library can be saved and restored. Rapidfire also keeps its own copies before any change that removes much.
  • Files and iCloud Sync
    Triggers that open files need access to the folders those files are in. The library itself can be kept the same on every Mac through iCloud. This page covers both.
  • AI Assistants
    An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.
  • Automation
    Rapidfire works with other tools on the Mac. Other apps can show a palette, add triggers, and read what is kept in Rapidfire, through links, through the Shortcuts app, and by dragging and copying.
  • Spotlight and Siri
    Palettes and triggers can be found by name in Spotlight and asked for through Siri, without opening Rapidfire first.
  • Watching and Presenting
    The overlay can be kept open, redrawn as the library changes, and unfolded to show everything at once. Together with a few links and settings, this makes it possible to follow an AI assistant at work, and to demonstrate or record Rapidfire without touching the keyboard.
  • Settings
    Every setting, pane by pane, with what it changes. Settings opens with ⌘, from the overlay, the editor and the menu bar icon’s menu.
  • License
    Rapidfire works without a license with the General palette. A license, bought once, adds more palettes and everything built on them, on 3 Macs.
  • Accessibility
    Rapidfire is built to be used with VoiceOver, Voice Control, Switch Control, a keyboard alone, one hand, low vision, and without relying on color, motion or sound. This page lists what it does for each and which settings help.
  • Keyboard Shortcuts
    Every key Rapidfire uses, on one page. The menu bar icon’s menu opens this page directly: Control-click the icon and choose Keyboard Shortcuts.
  • Troubleshooting and Privacy
    What to check when something does not work as expected, where Rapidfire keeps its data, and what it does and does not do with it.
