AI Assistants

An AI assistant can read and edit the library through Rapidfire’s MCP server: build a palette for a new project, tidy names, or move triggers, in one request. This page covers connecting an assistant, what it can do, and how every change stays visible and reversible.

What MCP Is For

MCP (Model Context Protocol) is a way for an AI assistant to use the tools of an app. Rapidfire offers its editing commands as such tools. An assistant connected to it can be asked, in plain words, to do what would otherwise be many steps in the editor.

  • “Make a palette for the Flutter project with the documentation, the issue tracker and the package site, and show it inside Dev.”
  • “Add the macros from BetterTouchTool as triggers.”
  • “These names are long. Suggest shorter ones that keep the keys of the triggers used most.”
  • “Find duplicate links and empty palettes.”

The server runs inside Rapidfire, on this Mac only. It accepts connections from programs on the same Mac that present its token. Nothing is sent to Deposombe, and Rapidfire contains no AI of its own.

Turn the Server On and Connect

  1. Open Settings > MCP and turn on MCP Server. The menu bar icon’s menu has Turn MCP Server On for the same switch, and so has the MCP button in the editor’s toolbar.
  2. Give the assistant the server’s address and token, following the assistant’s own instructions for adding an MCP server over HTTP. Settings > MCP shows the address and copies both; the menu bar icon’s menu has Copy MCP Address and Copy MCP Token. The token is sent as the header Authorization: Bearer, followed by the token.
  3. For Claude Code, Copy Setup Command in Settings > MCP copies one line that does this; run it in Terminal.
  4. Start a new conversation in the assistant, so that it reads the list of tools.
Turn off afterHow long the server stays on with no request from an assistant before it switches itself off. The countdown restarts with every request.
PortThe local port the server listens on. Change it only when another program needs the same port.
AddressWhere an assistant connects: this Mac only (127.0.0.1), the port, and /mcp.
TokenThe secret an assistant presents. Copy puts it on the clipboard; Regenerate replaces it, and every assistant then needs the new one.

The server is off by default and switches itself off when idle. While it is on, a dot shows at the top right of the menu bar icon. Leave it on only for as long as an assistant is being used.

What an Assistant Can Do

ReadList palettes and triggers, search by name, and see every trigger’s keys in each hand mode.
Add and editAdd triggers, rename them, change links and aliases, move triggers between palettes, and delete them.
Arrange palettesCreate, rename, reorder and delete palettes; set a prefix and an icon; show a palette inside another; switch a dynamic palette.
Hotkeys and settingsAdd, change and remove hotkeys; read and change settings.
Import and exportPrepare palettes for the Import window to confirm, and export palettes.
CheckReport what could be tidied: empty palettes, palettes that cannot be reached, duplicate links, long keys, and keys that need Shift.
Review and revertList its own recent changes and take one back.
OpenOpen a trigger, as picking it would.
  • Before a change, an assistant can ask what it would do, a dry run, and receives the result without anything being saved.
  • After every change, the reply lists the triggers whose keys moved and whether each is used often, so an assistant can choose names that disturb little.
  • Links are left out of what an assistant reads unless it asks for them, since a link can be private.

The Tools

The server offers these tools. An assistant chooses among them by itself; the names matter only when reading MCP Activity or an assistant’s own account of what it did.

list_palettesLists every palette with its prefix, icon, hotkeys, where it is shown, and how many triggers it holds.
list_triggersLists triggers with their keys in each hand mode, and which are used often.
search_triggersFinds triggers by name or alias, in every palette.
add_triggersAdds triggers to a palette. They are marked New.
update_triggersRenames triggers and changes their links or aliases, several at once, all or none.
move_triggersMoves triggers to another palette.
delete_triggersDeletes triggers.
create_paletteMakes a palette, optionally with a prefix and shown inside another.
update_paletteChanges a palette’s name, prefix, icon and other settings.
move_paletteChanges a palette’s place in the sidebar.
show_palette_insideShows a palette inside another, as All Triggers or One Entry, or stops showing it there.
delete_palettesDeletes palettes with their triggers.
add_hotkey, update_hotkey, remove_hotkeyAdd, change and remove a palette’s hotkeys.
switch_paletteChanges which palette a dynamic palette shows.
open_triggerOpens a trigger, as picking it would.
audit_libraryReports what could be tidied.
import_palettesPrepares palettes for import: as a preview, or in Rapidfire’s Import window to be confirmed there.
export_palettesReturns palettes in the format Rapidfire imports.
list_linksLists Rapidfire’s links, with the ready link for each palette.
get_settings, update_settingsRead and change settings.
list_activityLists recent changes made through MCP, with whether each can still be reverted.
revert_changeTakes one of those changes back.

Every tool that changes something accepts a dry run, and replies with the keys that moved.

What an Assistant Cannot Do

  • Set or remove locked keys. They are a deliberate choice made in the editor.
  • Fill in a trigger’s input fields. Rapidfire shows the fields, and only the person at the Mac types into them.
  • Reach anything outside Rapidfire: it has no access to files, to other apps or to the network through this server.
  • Read usage counts. It learns only whether a trigger is used often.

Keep Track of Changes

Every change made through MCP is recorded with its time, the assistant that made it, and the old and the new value.

  • The MCP button in the editor’s toolbar shows the latest changes.
  • MCP Activity, in the menu bar icon’s menu and in Settings > MCP, lists all of them for the last 30 days. Select a change and click Revert to take it back.
  • Edit > Undo (⌘Z) undoes a change made by an assistant like any other.
  • A trigger added by an assistant is marked New, and one whose link it changed is marked Changed, until it has been opened once from the overlay.

An assistant acts on what it reads. A web page or a document it is given could contain instructions that make it change a trigger’s link. The marks and the activity list exist so that such a change is seen. Check what a marked trigger opens before relying on it.

Watch an Assistant Work

With watching on, the overlay stays open while the assistant works and shows each trigger as it is added.

  1. Open the overlay and press ⌘K, or click the pin in its top row.
  2. Drag the overlay by its top row, or by the margin around the list, to a place beside the assistant’s window.
  3. Give the assistant its task.
  4. Press ⌘T at any time to see every folder opened.
  • Watching and Presenting: The overlay can be kept open, redrawn as the library changes, and unfolded to show everything at once. Together with a few links and settings, this makes it possible to follow an AI assistant at work, and to demonstrate or record Rapidfire without touching the keyboard.
  • Automation: Rapidfire works with other tools on the Mac. Other apps can show a palette, add triggers, and read what is kept in Rapidfire, through links, through the Shortcuts app, and by dragging and copying.
  • Sharing and Backups: Palettes can be given to other people as a file or as a link, and the whole library can be saved and restored. Rapidfire also keeps its own copies before any change that removes much.
